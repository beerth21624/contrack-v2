# โมดูล 2 — หาร้านวัสดุ / ขอราคาวัสดุ : แผนระดับกลาง

สถานะ: **แผนทิ้งไว้ ยังไม่เริ่ม** (ร่าง 26 ต.ค. 2026) — ทำหลังโมดูล 1 ถึง M3 เป็นอย่างน้อย
flag: `materials` (ระดับระบบ + workspace ตาม [README](README.md) §1) ; ตาราง prefix `mt_`

---

## 1. เป้าหมายและคุณค่า
- ผู้รับเหมาได้ **รายการวัสดุพร้อมปริมาณรวมเผื่อ** จาก BOQ (คอลัมน์ H ของทุกแถว + ตารางสรุปวัสดุงานโครงสร้าง) โดยไม่ต้องพิมพ์ซ้ำ → ส่งขอราคาหลายร้าน → เทียบ **ราคาถึงหน้างาน** กับราคาวัสดุใน BOQ (คอลัมน์ I) → ออกใบสั่งซื้อ → รับของหน้างาน → ต้นทุนวัสดุจริง vs ประมาณการ
- ร้านวัสดุได้ lead ที่มีปริมาณ-สเปก-กำหนดส่งชัด และข้อมูลพอให้ตัดสินใจเรื่อง **เครดิตเทอม**
- ผลพลอยได้: จุดข้อมูลราคาจริงรายพื้นที่ (ใช้ในเฟส 3)

## 2. สิ่งที่ใช้ซ้ำจากโมดูล 1 (เหตุผลที่ต้องทำหลัง)
- ตัวตนคู่ค้า: `sc_vendor_profiles` ขยายเป็น "คู่ค้า" ที่มี `kind: 'subcontractor' | 'supplier' | 'both'`; ทะเบียนทีมช่างกลายเป็น "ทะเบียนคู่ค้า" (ซับ + ร้าน) ใช้หน้าจอเดิม
- กลไกคำเชิญด้วยลิงก์ + OTP + inbox + แจ้งเตือน (LINE/SMS) + file storage + PDF + ModuleGuard — ใช้ทั้งหมด
- snapshot builder: เพิ่มโหมด "วัสดุ" (อ่าน H, I, unit, สเปกจากเครื่องคำนวณ เช่น ขนาดเหล็ก/ชนิดกระเบื้อง)
- ตารางเทียบ (leveling) + normalize: ใช้โครงเดียวกัน เปลี่ยนคอลัมน์ประเมินเป็น I และเพิ่ม "ค่าส่ง / ราคาถึงหน้างาน"

## 3. ผู้ใช้
| ฝั่ง | ใคร | ทำอะไร |
|---|---|---|
| ผู้ซื้อ | ผู้รับเหมา (บทบาทเดิม + `procurement.*`) | สร้างล็อตซื้อ ส่ง RFQ เทียบ ออก PO รับของ บันทึกจ่าย |
| ร้าน | ร้านวัสดุท้องถิ่น, ตัวแทนจำหน่าย, โรงงาน (เสาเข็ม/พื้นสำเร็จ/โครงหลังคาสำเร็จ) | ตอบราคา (มือถือ/LINE), แจ้งของแทน, กำหนดส่ง, เครดิตเทอม, ยืนยัน PO, แจ้งส่งของ |

## 4. Flow หลัก
```
BOQ ─► "ขอราคาวัสดุ" ─► เลือกล็อต (เทมเพลตตามช่วงงาน) ─► ตรวจรายการ/สเปก/ยี่ห้อที่รับได้ ─► วันต้องการของ (จาก S-Curve − lead time)
   ─► เลือกร้าน 2–6 ราย (ทะเบียน + ร้านในพื้นที่ส่ง) ─► ร้านตอบใบเสนอราคา ─► ตารางเทียบ (ราคาถึงหน้างาน/หน่วย, เครดิต, ส่งได้วันไหน)
   ─► เลือกคนละร้านต่อรายการได้ ─► ใบสั่งซื้อ (PO) ต่อร้าน ─► ร้านยืนยัน/แจ้งส่ง ─► รับของหน้างาน (GRN, รูป, ของขาด/เสีย) ─► บันทึกจ่าย/เครดิตครบกำหนด
```

### 4.1 ล็อตซื้อ (Material lot) — เทมเพลตตามช่วงงาน
| ล็อต | แถว BOQ ที่ดึง | หมายเหตุ |
|---|---|---|
| โครงสร้าง | เหล็กเส้นทุกขนาด (slot rebar), ลวดผูก, ปูน/หิน/ทราย หรือคอนกรีตผสมเสร็จ, ไม้แบบ, ไม้คร่าว, ตะปู | ให้เลือก "คอนกรีตผสมเสร็จ" แทนวัสดุผสมเอง (สลับแถว) |
| เสาเข็ม/พื้นสำเร็จ | หมวด 5, 10 (ของสั่งผลิต) | lead time ยาว แจ้งเตือนล่วงหน้า |
| ผนัง | อิฐ, ปูนก่อ, ปูนฉาบ, เสาเอ็น-ทับหลัง, ตะแกรง | |
| หลังคา | โครงเหล็ก, แป, กระเบื้องมุง, ครอบ, ฉนวน | แถวที่นับเป็น "แผ่น/ท่อน" ตามปัดเศษของ BOQ |
| ผิว | กระเบื้องพื้น/ผนัง, กาวซีเมนต์, ยาแนว, ฝ้า+โครงคร่าว | |
| สี | สีรองพื้น/สีจริง ตามรอบ | |
| ไฟฟ้า / ประปา | ท่อ สาย ตู้ อุปกรณ์ / ท่อน้ำ ข้อต่อ สุขภัณฑ์ | รายการยาว ใช้ pick-list เดิม |

- แต่ละรายการ: รายการ, สเปก (จากเครื่องคำนวณ), หน่วย, ปริมาณ H, **ยี่ห้อ/เกรดที่รับได้** (chips: ตามแบบ / เทียบเท่าได้ / ระบุ), วันต้องการ, แบ่งส่งหลายงวดได้ (เหล็ก 2 เที่ยว)
- ราคาประเมิน (I) ซ่อนจากร้าน

### 4.2 ใบเสนอราคาของร้าน (มือถือ)
ต่อรายการ: ราคา/หน่วย, ยี่ห้อ/รุ่นที่เสนอ (ของแทนติ๊ก "เทียบเท่า"), มีของ/สั่งผลิต, ส่งได้วันที่; รวม: ค่าส่ง (ต่อเที่ยว/รวม), ขั้นต่ำ, ราคายืนถึง, **เงื่อนไขชำระ** (เงินสด / โอนก่อนส่ง / เครดิต 30/45/60 วัน / วงเงิน), VAT รวมหรือไม่, หมายเหตุ

### 4.3 ตารางเทียบ
คอลัมน์ประเมิน = I (BOQ) · ต่อร้าน: ราคา/หน่วย, **ราคาถึงหน้างาน/หน่วย** (= ราคา + ค่าส่งกระจายตามมูลค่า), ยี่ห้อ, ส่งได้วันที่ (เทียบวันต้องการ: ทัน/ช้า n วัน), เครดิต; เลือกร้านต่อรายการ → "ยอดรวมถ้าเลือกตามนี้" และจำนวน PO ที่จะเกิด; เตือนเมื่อแยกร้านแล้วค่าส่งรวมสูงกว่าซื้อร้านเดียว

### 4.4 PO → ส่งของ → รับของ
- PO ต่อร้าน (PDF, เลขที่, ที่อยู่ส่ง, ผู้รับ, งวดส่ง) → ร้านยืนยัน / เสนอแก้วันส่ง
- ร้าน "แจ้งส่งของ" (วัน เที่ยว รายการ) → หน้างานกด "รับของ" จากมือถือ: จำนวนรับจริง, ของขาด/เสีย + รูป → ระบบออกบันทึกส่วนต่างให้ร้าน
- บันทึกจ่าย + วันครบกำหนดเครดิต → ปฏิทินเจ้าหนี้ระดับ workspace (คู่กับสมุด retention ของโมดูล 1 = หน้า "ภาระจ่าย")
- ต้นทุนวัสดุจริงต่อหมวดเทียบ J ของ BOQ → รายงานประมาณการ vs จริง (รวมค่าแรงจากโมดูล 1 → ครบทั้ง M)

## 5. ฝั่งร้าน
- โปรไฟล์ร้าน: ชื่อ, ที่ตั้ง, **พื้นที่จัดส่ง** (จังหวัด/อำเภอ หรือรัศมี), หมวดสินค้า, ยี่ห้อหลัก, นโยบายเครดิตเบื้องต้น, รถส่ง, เวลาทำการ
- inbox: RFQ ใหม่ (เรียงวันปิดรับ) · ส่งราคาแล้ว · PO · ส่งของ/ค้างชำระ
- เห็นข้อมูลผู้ซื้อ: ชื่อบริษัท, จำนวน PO/ยอดซื้อ/ประวัติจ่ายตรงเวลาบนแพลตฟอร์ม (ซึ่งผู้ซื้อเลือกเปิด) → ตัดสินใจเครดิต

## 7. Milestones (หลังโมดูล 1 M3)
| M | เนื้อหา | ประมาณ |
|---|---|---|
| N0 | ขยายคู่ค้าเป็น ซับ/ร้าน, โปรไฟล์ร้าน, snapshot โหมดวัสดุ + เทมเพลตล็อต (domain + tests) | 1.5 สัปดาห์ |
| N1 | สร้าง RFQ วัสดุ, ส่งคำเชิญ, guest view, ใบเสนอราคาร้าน, inbox ร้าน | 2.5 สัปดาห์ |
| N2 | ตารางเทียบราคาถึงหน้างาน, เลือกคนละร้านต่อรายการ, PO + PDF, ร้านยืนยัน | 2 สัปดาห์ |
| N3 | แจ้งส่ง/รับของ/ส่วนต่าง, เจ้าหนี้-ครบกำหนดเครดิต, รายงานวัสดุจริง vs J, รวมรายงาน "ภาระจ่าย" กับ retention | 2 สัปดาห์ |
| N4 | price observations (anonymized), แจ้งเตือน lead time, แข็งแรง/PDPA | 1 สัปดาห์ |

## 8. คำถามเปิด
- ร้านรายใหญ่ (SCG Home, ไทวัสดุ, โกลบอลเฮ้าส์) จะเข้าแพลตฟอร์มด้วยช่องทางไหน — เริ่มจากร้านท้องถิ่นที่ผู้รับเหมาซื้ออยู่แล้ว (ทะเบียนส่วนตัว) เหมือนโมดูล 1
- คอนกรีตผสมเสร็จ/เสาเข็ม/พื้นสำเร็จ เป็น "วัสดุ" หรือ "จ้างช่วง" — รองรับทั้งสองทางโดยให้เลือกตอนสร้างล็อต
- Yello ของ BUILK ทำรวมออเดอร์ต่อรองโรงงาน — เราไม่ทำในเฟสนี้ (ไม่ถือสต็อก ไม่เป็นคู่สัญญาซื้อขาย)
