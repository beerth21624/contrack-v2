## รีวิว 4 ด้าน (แก้แล้วทั้งหมด)
- ความปลอดภัย/แยก tenant: ราคาหลุดทางแจ้งเตือน, ยึดลิงก์คำเชิญ (ต้องเบอร์ตรง), จำกัด SMS, ผู้ถูกถอนคำเชิญยังเห็นงาน, เดา OTP / ปลอม IP, ลิงก์ดิบในฐานข้อมูล
- เงินและสถานะ: กดซ้ำพร้อมกัน (lock + unique index), ยกเลิกแล้วตกลงจ้างใหม่ไม่ได้, ราคาก่อนแก้ไขแพ็กเกจ, ฐานภาษี, ปัดเศษ, รายงานจ่ายแล้ว
- หน้าเว็บ ↔ API: ทีมที่ปฏิเสธกินโควต้า, workspace ผิดในหน้าแพ็กเกจ, สิทธิ์ที่ตั้งค่าขยาย, cache ตั้งค่า
- เปิด-ปิดโมดูล: งานเบื้องหลัง, OTP/อัปโหลด, แอปทีมช่าง, กระดิ่ง, ลิงก์หน้าโมดูลเสริม

## ยังไม่ทำ / ข้อจำกัด
- LINE OA จริง (มี adapter stub), อัปเดตแบบ realtime (ใช้ polling 30 วิ), PDF ฝั่ง server (พิมพ์จากเบราว์เซอร์), กระดานงานเปิด (เฟส 2), rate limiter อยู่ในหน่วยความจำ (instance เดียว)
