# ทีมช่างและการจัดคนข้ามโครงการ — ร่างแนวคิด (brainstorm)

สถานะ: **W0, W1 และ W2 ทำเสร็จแล้ว (26 ต.ค. 2026)** — W3 เป็นต้นไปยังเป็นร่าง

ค่าตั้งต้นที่ใช้ใน W1 (เปลี่ยนได้): ช่าง/คนงานไม่ต้องเข้าระบบ · ค่าแรงมีทั้งรายคน (เห็นเฉพาะเจ้าของ/ผู้ดูแล) และระดับทีม (ชุดค่าแรงของบริษัท หรือเหมาต่อวัน) · ประเภทการจ้าง ประจำ / รายวัน / ผู้รับเหมาช่วง · ทีมเดียวกันจัดซ้อนวันได้ (ระบบเตือน ไม่บล็อก) · เปิด-ปิดด้วย `MODULES_ENABLED=workforce`
เกี่ยวข้อง: หน้า Man-Day (อัตราค่าแรงชุด A/B) · ปฏิทินงาน · โมดูล 1 จ้างช่วง (`docs/marketplace/01-module1-subcontracting-plan.md`, ประเภทงานช่าง 12 ประเภท `src/domain/subcontracting/trades.ts`)

---

## 0. สรุปใน 1 หน้า

**ปัญหา:** บริษัทหนึ่งถือหลายโครงการพร้อมกัน แต่ละโครงการมีช่วง "รอ" ที่คนว่าง — รอคอนกรีตเซ็ตตัว, รอปูนฉาบแห้งก่อนทาสี, รอสีแห้งระหว่างรอบ. ถ้าไม่มีใครมองภาพรวม ทีมก็ยืนรอ (เสียค่าแรงหรือเสียทีมไปรับงานที่อื่น) หรือบางโครงการขาดคนจนช้า.

**สิ่งที่ฟีเจอร์นี้ทำ:**
1. **คลังทีมและบุคลากรของบริษัท** — ทีมช่างแต่ละสาย (โครงสร้าง ก่อฉาบ ไฟฟ้า ทาสี …), หัวหน้างาน/โฟร์แมน, ผู้คุมงาน, ช่างเดี่ยว พร้อมค่าแรงจริงของแต่ละคน/ทีม
2. **อัตราค่าแรงเป็นรายการ** (ขยายจากชุด A/B ในรูป) — A/B คือค่าตั้งต้นจาก Excel, เพิ่มชุดใหม่ได้ และเลือกในตัวเลือกของ Man-Day ได้
3. **จัดทีมเข้างาน** — งานแต่ละงานในแผน (32 งาน S-Curve) เลือกได้ว่าใช้ทีมไหน วันไหน
4. **กระดานจัดคนทั้งบริษัท** — แถว = ทีม, แนวนอน = วัน, แถบสี = โครงการ → เห็นทันทีว่าใครว่าง ใครชนสองที่ ช่วงรอของแต่ละโครงการอยู่ตรงไหน
5. **ผู้ช่วยจัดทีม** — ระบบชี้ว่า "ทีม ก. จะว่าง 12 วัน ช่วงรอปูนแห้งที่บ้านคุณวิชัย → ย้ายไปฉาบที่บ้านคุณสมศรีได้ เสร็จเร็วขึ้น 6 วัน" พร้อมตัวเลขเทียบก่อน/หลัง

**หลักที่ยึด:** ใช้ได้ตั้งแต่ทีมแรกที่บันทึก (ไม่ต้องกรอกทุกคนก่อน) · ตัวเลขที่ระบบแนะนำต้องอธิบายได้ (ไม่ใช่กล่องดำ) · ไม่เปลี่ยนสูตร Excel เดิม (BOQ, Man-Day, S-Curve คำนวณเหมือนเดิม) · **ปิดโมดูลได้ทั้งก้อน** แล้วระบบกลับเป็น BOQ ธรรมดา ข้อมูลไม่หาย

## 1. คำศัพท์และข้อมูลหลัก

| สิ่ง | คืออะไร | ข้อมูลสำคัญ |
|---|---|---|
| **บุคลากร** (person) | คนหนึ่งคน ไม่จำเป็นต้องเป็นผู้ใช้ระบบ | ชื่อ, เบอร์, บทบาท (หัวหน้างาน / ช่าง / คนงาน / ผู้คุมงาน / วิศวกร), สายงาน (จาก 12 ประเภท), ค่าแรงต่อวัน, ประเภทการจ้าง (ประจำ / รายวัน / ผู้รับเหมาช่วง) |
| **ทีมช่าง** (crew) | กลุ่มที่ทำงานด้วยกัน มีหัวหน้า | ชื่อทีม, สายงานหลัก, หัวหน้าทีม, สมาชิก **หรือ** แค่จำนวน (ช่าง 3 · คนงาน 2) สำหรับทีมที่ไม่อยากกรอกรายคน, ค่าแรงทีมต่อวัน (รวมจากสมาชิก หรือใช้อัตราค่าแรงชุดใด) |
| **อัตราค่าแรง** (rate card) | ชุดค่าแรงช่าง/คนงานต่อวัน | A (งานทั่วไป 800/500) และ B (หลังคา ไฟฟ้า ฝ้า สี อลูมิเนียม เบ็ดเตล็ด 1,000/600) มาจาก Excel; เพิ่มชุดของบริษัทได้ เช่น "ทีมไฟฟ้า ช่างพงษ์ 1,200/650" |
| **การจัดทีม** (assignment) | ทีม × โครงการ × งานในแผน × ช่วงวัน | แผน (วันเริ่ม-จบ) และจริง (เข้างานจริงกี่วัน) |
| **ช่วงรอ** (waiting window) | ช่วงที่งานต้องหยุดรอตามธรรมชาติวัสดุ | ผูกกับงาน: "หลังเทฐานรากรอ 7 วัน", "ฉาบแล้วรอ 14 วันก่อนทาสีรองพื้น" — ค่าตั้งต้นแก้ได้ |
| **ผู้คุมงาน** (site supervisor) | คนรับผิดชอบโครงการหน้างาน คุมได้หลายโครงการ | โครงการที่คุม, วันที่เข้าแต่ละไซต์ |

ทีมของผู้รับเหมาช่วงจากโมดูล 1 (vendor profile) **เป็นทีมช่างประเภทหนึ่ง** บนกระดานเดียวกัน — ไม่ต้องสร้างซ้ำ.

## 2. อัตราค่าแรงหลายชุด (ขยายจากรูปที่ส่งมา)

**ตอนนี้:** หน้า Man-Day มี 2 ชุด (A, B) และแต่ละงานเลือก A หรือ B.

**ข้อเสนอ:**
- ระดับ **บริษัท (workspace):** คลังอัตราค่าแรง — A, B เป็นค่าตั้งต้น (แก้ค่าได้ ลบไม่ได้) + เพิ่มชุดใหม่ ตั้งชื่อเอง
- ระดับ **โครงการ:** ตัวเลือก "ชุดค่าแรง" ของแต่ละงานใน Man-Day แสดงทุกชุดของบริษัท + ทีมที่จัดเข้างานนั้น (ถ้าเลือกทีม ค่าแรงต่อวันมาจากทีมจริง)
- ค่าที่ใช้ในโครงการ **ถูกเก็บไว้กับโครงการ** ตอนเลือก (snapshot) — แก้อัตราของบริษัททีหลัง ไม่ทำให้ BOQ เก่าเปลี่ยนเองโดยไม่รู้ตัว; มีปุ่ม "อัปเดตเป็นอัตราล่าสุด"
- สูตรเดิมไม่เปลี่ยน: ค่าแรงต่อวัน = ช่าง × อัตราช่าง + คนงาน × อัตราคนงาน → วันที่คำนวณ = ค่าแรงใน BOQ ÷ ค่าแรงต่อวัน (Excel) · โครงการที่ใช้แค่ A/B ได้ผลเท่าเดิมทุกบาท

ข้อนี้ทำได้ก่อนเรื่องอื่นทั้งหมด และมีประโยชน์ทันทีแม้ไม่เปิดโมดูลจัดคน.

## 3. หน้าจอ

### 3.1 ทีมและบุคลากร (เมนูบริษัท)
- รายการทีม: ชื่อ สายงาน หัวหน้า จำนวนคน ค่าแรงต่อวัน **และ "ตอนนี้อยู่ที่ไหน"** (โครงการ/ว่าง/ถึงวันไหน)
- รายการบุคลากร: ค้นหาตามสายงาน, ดูประวัติว่าเคยอยู่โครงการไหน
- เพิ่มทีมแบบเร็ว: ชื่อ + สายงาน + จำนวนช่าง/คนงาน + ชุดค่าแรง (ไม่ต้องกรอกรายคน)

### 3.2 ในโครงการ: แท็บ "ทีมงาน"
- ผู้คุมงานของโครงการ
- ตาราง 32 งานตามแผน: งาน · ช่วงวันตามแผน · คนที่ต้องใช้ (จาก Man-Day) · **ทีมที่จัด** (เลือกจากรายการ เห็นว่าทีมว่างช่วงนั้นไหม)
- ปฏิทินงานที่เพิ่งทำ แสดงชื่อทีมแทนแค่จำนวนคน

### 3.3 กระดานจัดคน (ทั้งบริษัท) — หัวใจของฟีเจอร์
```
              ต.ค. สัปดาห์ 3        สัปดาห์ 4          พ.ย. สัปดาห์ 1
ทีมโครงสร้าง ก. [■■ บ้านวิชัย ฐานราก ■■][░ รอปูน 7 วัน ░][■ บ้านวิชัย คานคอดิน ■]
ทีมก่อฉาบ ข.    [■■■■ บ้านสมศรี ก่ออิฐ ■■■■■■■■][      ว่าง 9 วัน      ]
ทีมทาสี ค.      [ว่าง][■ บ้านวิชัย รองพื้น ■][■ บ้านสมศรี ■ ⚠ ชน 2 วัน]
```
- แถบสีตามโครงการ, ช่วง "รอ" เป็นลายจาง, "ว่าง" เป็นช่องเปล่า, **ชนกัน** เป็นสีแดงพร้อมเหตุผล
- ลากแถบเพื่อย้ายทีม/เลื่อนวัน → ระบบคำนวณผลทันที (ข้อ 4)
- สรุปบนสุด: อัตราการใช้ทีม (%), วันว่างรวม, จุดชน, โครงการที่เสี่ยงช้า

### 3.4 มือถือของหัวหน้างาน (เฟสหลัง)
- เช็กชื่อเข้างานรายวัน (ใครมา กี่คน ที่ไซต์ไหน) → เป็น "ผลงานจริง" ให้ S-Curve และค่าแรงจริงโดยไม่ต้องกรอกซ้ำ
- ใช้การเข้าระบบด้วยเบอร์โทร + OTP แบบเดียวกับฝั่งทีมช่างของโมดูล 1

## 4. ระบบช่วยคิด — ตอบคำถามที่เจ้าของอยากรู้

| คำถาม | ระบบตอบอย่างไร | ตัวเลขที่ใช้ |
|---|---|---|
| วางทีมแบบนี้ดีไหม | เทียบ "ก่อน/หลัง" ทุกครั้งที่ย้าย | วันเสร็จแต่ละโครงการ, วันว่างรวมของทีม, ค่าแรงรวม, จุดชน |
| ช่วยลดเวลาจริงไหม | วันเสร็จโครงการ = งานสุดท้ายจบ โดยงานจะเริ่มได้เมื่อ (ก) งานก่อนหน้า + ช่วงรอครบ และ (ข) ทีมว่าง | วันเสร็จเดิม → ใหม่ (เร็วขึ้น/ช้าลงกี่วัน) |
| ทีมจะว่างกี่วัน | ช่องว่างระหว่างการจัดทีมแต่ละครั้งบนกระดาน | วันว่าง × ค่าแรงต่อวัน = มูลค่าที่เสียไป (ทีมประจำ) หรือ "เสี่ยงเสียทีม" (ทีมรายวัน) |
| ควรไปโครงการไหนต่อ | หางานที่ (1) สายงานตรง (2) อยู่ในช่วงที่ว่าง (3) พร้อมเริ่มแล้ว (งานก่อนหน้าเสร็จ) (4) โครงการเสี่ยงช้ามากที่สุดก่อน | เรียงคำแนะนำ 3 อันดับ พร้อมเหตุผลเป็นประโยค |

**ตัวชี้วัดหลัก (ตั้งชื่อไทย):**
- **อัตราการใช้ทีม** = วันที่มีงาน ÷ วันทำงานที่ทีมพร้อม
- **วันว่าง** และ **มูลค่าวันว่าง**
- **วันที่ประหยัดได้** (ต่อโครงการ และรวม)
- **ค่าแรงต่อโครงการ** จริงเทียบ BOQ

**แนวทางทำ (ไม่ over-promise):**
1. ขั้นแรก **ตรวจจับ** — ชนกัน, ช่องว่าง, งานพร้อมเริ่มแต่ไม่มีทีม (กฎตรงไปตรงมา อธิบายได้)
2. ขั้นสอง **แนะนำทีละจุด** — "ย้ายทีม ข. ไปบ้านสมศรี 9 วัน: บ้านสมศรีเสร็จเร็วขึ้น 6 วัน ทีม ข. ไม่ว่าง" ผู้ใช้กดยอมรับ/ไม่
3. ขั้นสาม **จัดให้ทั้งกระดาน** (เลือกเป้าหมาย: เสร็จเร็วสุด / ทีมว่างน้อยสุด / ค่าแรงต่ำสุด) — เป็นปัญหาจัดตารางที่มีทรัพยากรจำกัด ใช้วิธีจัดลำดับความสำคัญแบบ heuristic ก่อน ผลต้องดูและแก้ได้ก่อนยืนยัน

## 5. ต้องเพิ่มอะไรในแผนงานเดิม (ไม่แตะสูตร Excel)

- **ลำดับงานและช่วงรอ:** ตอนนี้วันเริ่มแต่ละงานพิมพ์เอง (ตาม Excel) ไม่มีความสัมพันธ์กัน. เพิ่ม "ต้องเสร็จก่อน + รอกี่วัน" ต่องาน (ใช้กติกาเดียวกับลำดับขั้นตอนจาก PDF ที่ทำไปแล้ว) เพื่อให้ระบบ *แนะนำ* วันเริ่ม — ค่าวันเริ่มที่ผู้ใช้พิมพ์ยังเป็นตัวจริงที่ใช้คำนวณ S-Curve
- **ปฏิทินวันทำงาน:** Excel นับทุกวันไม่เว้นวันหยุด. กระดานจัดคนต้องรู้วันหยุดของทีม (อาทิตย์, สงกรานต์, ลา) — เก็บแยก ไม่เปลี่ยนการนับวันของ S-Curve เดิม (เป็นตัวเลือกภายหลัง)

## 6. โครงสร้างระบบ (ร่าง)

- โมดูลใหม่ **"ทีมช่างและการจัดคน"** ในระบบโมดูลเสริมเดิม (เปิด-ปิด 2 ชั้น: ระบบ + ต่อ workspace) — ปิดแล้วเมนู/หน้า/ API ของโมดูลหาย ข้อมูลยังอยู่, Man-Day กลับใช้ A/B ตามที่ snapshot ไว้
- ข้อมูลอยู่ระดับ **workspace** (ตารางของโมดูล) ไม่อยู่ใน `project_docs` ของ BOQ: `people`, `crews`, `crew_members`, `rate_cards`, `crew_assignments` (project, task id, crew, ช่วงวันแผน/จริง), `availability` (วันหยุด/ลา), `task_lags` (ช่วงรอต่อโครงการ)
- ใช้ realtime เดิม: ย้ายทีมแล้วกระดานของทุกคนเปลี่ยนทันที + soft lock ระดับแถบงาน
- สิทธิ์: เจ้าของ/ผู้ดูแล จัดการทีมและเห็นค่าแรงรายคน · ผู้ประมาณราคา จัดทีมเข้างานในโครงการได้ เห็นค่าแรงระดับทีม · ผู้ดูอย่างเดียว ดูกระดานได้ ไม่เห็นค่าแรง
- ข้อมูลส่วนบุคคล (เบอร์โทร ค่าแรง) — ตาม PDPA: เก็บเท่าที่จำเป็น, จำกัดคนเห็น, ลบได้เมื่อเลิกจ้าง

## 7. ลำดับการทำ (เสนอ)

| เฟส | ส่งมอบ | คุณค่าที่ได้ทันที |
|---|---|---|
| **W0** ✅ | อัตราค่าแรงหลายชุดระดับบริษัท + เลือกใน Man-Day (ข้อ 2) | ประมาณราคาด้วยค่าแรงจริงของทีมตัวเอง |
| **W1** ✅ | คลังทีม/บุคลากร + จัดทีมเข้างานในโครงการ + ปฏิทินแสดงชื่อทีม | รู้ว่างานไหนใครทำ |
| **W2** ✅ | กระดานจัดคนข้ามโครงการ + ตรวจจับชน/ว่าง + ช่วงรอต่องาน | เห็นภาพรวมบริษัท ไม่ส่งทีมชนกัน |
| **W3** | เทียบก่อน/หลัง + คำแนะนำทีละจุด + ตัวชี้วัด | ตัดสินใจย้ายทีมด้วยตัวเลข |
| **W4** | มือถือหัวหน้างาน (เช็กชื่อ → ผลงานจริง) + ผูกทีมผู้รับเหมาช่วง (โมดูล 1) | ข้อมูลจริงไหลเข้า S-Curve/Cash Flow เอง |
| W5 | จัดให้ทั้งกระดานตามเป้าหมาย | ประหยัดเวลา/คนแบบอัตโนมัติ |

## 8. คำถามถึงเจ้าของระบบ

1. ช่าง/คนงานต้อง **เข้าระบบเอง** ไหม หรือมีแค่หัวหน้างานที่ใช้มือถือ?
2. ค่าแรงคิด **รายคนรายวัน** หรือ **เหมาเป็นทีม** หรือทั้งสองแบบ?
3. ทีมประจำ (จ่ายทุกวันแม้ว่าง) กับทีมรายวัน (ว่าง = ไม่จ่าย แต่เสี่ยงหาย) — มีทั้งสองแบบใช่ไหม? ระบบจะแสดง "ต้นทุนวันว่าง" ต่างกัน
4. **ช่วงรอมาตรฐาน** ที่ใช้จริง (เช่น ฐานราก/พื้นรอกี่วัน, ฉาบก่อนทาสีรอกี่วัน, สีแต่ละรอบ) — อยากได้ตัวเลขจากประสบการณ์เจ้าของเป็นค่าตั้งต้น
5. **ระยะทางระหว่างไซต์** สำคัญไหม (ย้ายทีมข้ามจังหวัดไม่คุ้ม)?
6. วันหยุดทีม: หยุดวันอาทิตย์ทุกทีมไหม?
7. ทีมผู้รับเหมาช่วงจากโมดูล 1 ให้อยู่บนกระดานเดียวกันเลยใช่ไหม?
