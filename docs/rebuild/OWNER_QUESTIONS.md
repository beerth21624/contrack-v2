# คำถามถึงเจ้าของระบบ (รวบรวมจากการ rebuild)

ทุกข้อตอนนี้ระบบทำตาม Excel v5 หรือค่าที่แนะนำไว้แล้ว ใช้งานได้ — ตอบเพื่อปรับให้ตรงใจ ไม่ได้บล็อกงาน
(D1–D7 อนุมัติแล้ว; D8–D20 ยังไม่อนุมัติ จึงยึดพฤติกรรม Excel)

## A. ภาพรวมการเดินทีละด่าน (สำคัญสุด)
1. **ล็อกด่าน**: ตอนนี้ต้องผ่านด่านตามลำดับ แต่ย้อนกลับไปแก้ด่านที่ผ่านแล้วได้ทุกเมื่อ, หน้า BOQ เปิดดูได้ตลอด — โอเคไหม หรืออยากให้ข้ามไปด่านไหนก็ได้
2. **โครงการเริ่มจากแบบ (ว่าง)**: ขนาด/จำนวน = 0, ราคา/ % เผื่อ/สเปกมาตรฐานคงตาม Excel, แถวใหม่เติมขนาดเหล็กมาตรฐาน (DB12, RB6 @0.15 ฯลฯ) ให้ — โอเคไหม
3. **ค่าที่ยังคิดเงินแม้โครงการว่าง** (เพราะ Excel ตั้งเป็นเหมา): ตรวจสอบที่ดิน 7,500 (นอกยอดก่อสร้าง), ตู้ไฟชั่วคราว 30A 1,200 + ค่าแรง 1,500, วางผัง/ปักหมุดเหมา 5,500 — ควรเริ่มเป็น 0 หรือคงไว้
4. **แผนงาน (Man-Day / S-Curve / CashFlow) ของโครงการว่าง** ยังใช้วันที่และทีมงานตัวอย่าง (ม.ค. 2026) — ควรเริ่มจากวันนี้/ว่างไหม
5. ด่าน "ไม่มีงานนี้" มีที่: รื้อถอน, ถมดิน, เสาเข็ม, พื้นสำเร็จรูป, พื้นดาดฟ้า, บันได, ตกแต่งผนัง — ควรเพิ่ม/ลดด่านไหน

## B. ราคาและค่ามาตรฐาน
6. ราคาเสาเข็มต่อต้นมักเป็นใบเสนอราคา — ควรอยู่หน้าหลักแทนที่ซ่อนใน "ราคาและค่าตั้งต้น" ไหม
7. ดินถม: Excel ราคา 0 (ลูกค้าจัดหาเอง) — ด่านถมดินควรมีช่องราคาไหม
8. แคมป์คนงาน/วางผัง: ราคาต่อห้อง/เหมามาจาก BOQ ที่พิมพ์ใน Excel ไม่ได้คำนวณจากวัสดุ — ให้แก้ราคาในด่านได้ไหม (D8: ชีต Google ภายนอกของแคมป์/วางผังยังไม่ได้รับ)
9. เชิงชาย: ราคาวัสดุ 50 ในหมวด 23 แต่ 20 ในหมวด 25/31 — ตั้งใจไหม (O-10)
10. ความสูงเชิงชาย 0.23 ม. (ทาสี) — ใช้เป็นค่ามาตรฐานได้ไหม

## C. โครงสร้าง
11. ความลึกหลุมฐานรากเริ่ม 0 (ต้องกรอก ไม่งั้นดินถมกลับติดลบ — มีเตือน) หรือเริ่ม 1.3 ม. ตาม Excel
12. ชื่อ F/C/B/S: Excel มีแค่ F1,F2,F4 / C1–C3 / B1–B6 / S1–S2 — เปิดให้พิมพ์ชื่ออื่น (F3, C4, B7) ได้ไหม
13. คานหลังคา: หนึ่งแถว = รวมทุกช่วง (ตอนนี้) หรือแถวละช่วง
14. ความลึกทรายใต้พื้น/ดินถมใต้พื้น (0.40) ซ่อนเป็นค่ามาตรฐาน — ควรแสดงไหม

## D. หลังคา ผนัง ฝ้า สี
15. ความชันหลังคาเริ่ม 0 (มีเตือน) หรือ 40°; แถวปั้นลมใน Excel ล็อก 40° — ให้ตามความชันหลังคาได้ไหม
16. ฝ้าลาดเอียง: ช่ององศาต่อแถว (ตอนนี้) หรือสวิตช์ "ลาดตามหลังคา"
17. D20 ทาสี: ให้ดึงพื้นที่ระแนง/บัว/เชิงชายจากด่านก่อนหน้าอัตโนมัติไหม (ตอนนี้เป็นปุ่ม "ใช้ค่าจากด่าน…"); เชิงชาย 62.3 หรือ 63.2 ม.
18. ความหมายส่วนผนัง (legend ด่านก่ออิฐ) โดยเฉพาะ "ผนังภายนอกบ้าน" — ยืนยันคำอธิบาย
19. ด่านปูพื้นควรมีปุ่ม "คัดลอกห้องจากฝ้าเพดาน" ไหม

## E. ไฟฟ้า ประปา
20. ขนาดสายแนะนำอัตโนมัติ: ไฟแสงสว่าง 2.5/1.5 ×2, ปลั๊ก 4/2.5 ×3, เครื่องทำน้ำอุ่น/แอร์/ปั๊ม 4 ×3 — ใช้ได้ไหม
21. ระยะดิ่งต่อจุด: สวิตช์ 2.3 ม., ปลั๊ก 3.2 ม.; เบรกเกอร์ในตู้พิมพ์เอง ไม่ผูกกับจำนวนวงจร — ควรคำนวณจากวงจรไหม (D11)
22. รายการตู้ไฟเริ่มว่าง หรือเริ่มชุดมาตรฐาน (ตู้ 1, เมน 1, หลักดิน 1)
23. สาย THW 6 ไม่มีแถวใน BOQ (เหมือน Excel) — เพิ่มแถวไหม
24. ปุ่ม "เพิ่มชุดห้องน้ำ 1 ห้อง" (สุขภัณฑ์) — เก็บไว้ไหม (ไม่มีใน Excel)
25. ราคาในหน้ารายการเลือก (ไฟฟ้า/สุขาภิบาล/เบ็ดเตล็ด) ไม่มีในชีต Excel (Excel ใส่ราคาที่ BOQ) — เก็บไว้ไหม

## F. แผนงานและเงิน
26. D16: จำนวนวัน T ใช้ค่าที่ Excel พิมพ์ (มีปุ่ม "ใช้ค่าที่คำนวณ") หรือใช้ค่าคำนวณ round(S) เป็นหลัก
27. % ความคืบหน้ามีสองช่อง (S-Curve และ CashFlow) เหมือน Excel — รวมเป็นช่องเดียวไหม
28. งวดเงิน: วางงวดอัตโนมัติตามสัปดาห์ที่งานเสร็จไหม (Excel วางงวด 4/5 ช้ากว่างานเสร็จ)
29. CashFlow ขยายเกิน 5 เดือนให้ครอบคลุมแผน (Excel ตัดที่ 20 คอลัมน์ ทำให้ต้นทุนหาย) — โอเคไหม
30. หมวด 1 (รื้อถอน/ถมดิน) ไม่มีงานในแผน (เหมือน Excel) — ควรเตือนไหม

## G. เอกสารส่งออก
31. ใบ BOQ พิมพ์: เพิ่มจำนวนเงินตัวอักษร, % สัดส่วน, ช่องเซ็นชื่อ (ไม่มีใน Excel) — เก็บไว้ไหม
32. ไฟล์ Excel ส่งออก: แถวรายการเป็นค่าตัวเลข เฉพาะยอดรวมเป็นสูตร — พอไหม

## H. จากการเทียบสูตรกับ Excel จริง (oracle, 2026-10-26)
33. **หลังคา: × หรือ ÷ ตามหน่วย** — แอปเลือกคูณ/หารจากหน่วยในคอลัมน์ D (เช่น "ม./แผ่น" = หาร) แต่ Excel ล็อกสูตรต่อแถว ถ้าเปลี่ยนรายการในแถว 8 เป็นไม้เชิงชาย 4 ม./แผ่น Excel ได้ 250 แผ่น แอปได้ 16 แผ่น (ถูกตามหน่วย) — ยืนยันให้ใช้แบบแอปไหม
34. **ยอดรวมหมวด 1 (J14/L14/M14)** — Excel ไม่รวมแถว 12 (งานรื้อถอน) แอปรวม (ถือเป็นการแก้บั๊ก D1) — ยืนยัน
35. **พื้นสำเร็จรูปแผ่นที่ 15–17** — Excel ไม่มีสูตรน้ำหนักเหล็ก shear key ในแถว 22–24 จึงไม่คิดเหล็กของแผ่นเหล่านั้น แอปคิดครบ (ถือเป็น D1) — ยืนยัน
36. **ไฟล์ Excel เปิดใน Excel desktop ไม่ตรงกับ Google Sheets**: พื้นที่ห้องน้ำ (I5:I8) ได้ 0 ใน Excel desktop และการจับคู่ข้อความที่มีช่องว่างท้าย ("บานอลูมิเนียม ", "ฉาบภายใน ") ทำงานเฉพาะ Google Sheets — แอปยึดค่าแบบ Google Sheets (ค่าที่บันทึกในไฟล์)
37. ช่วยเช็คใน Google Sheets ว่า =ROUNDUP((0.75+0.6)/0.15,0) ได้ 9 (แอปได้ 9) — ถ้าได้ 10 จะเป็นความต่างเรื่องปัดเศษทศนิยม

## I. Backend / ทีม
38. รหัสผ่านใช้ scrypt (มาตรฐาน Node) แทน argon2 เพราะสภาพแวดล้อมนี้บล็อก native install script — เปลี่ยนเป็น argon2 ได้ภายหลังถ้าต้องการ
39. แยก tenant ด้วยโค้ด + foreign key (workspace_id คู่กับ project_id) — ต้องการเพิ่ม Row Level Security ของ Postgres เป็นชั้นป้องกันที่สองไหม
40. ยังไม่มีระบบส่งอีเมล: คำเชิญเป็น "ลิงก์ให้คัดลอกส่งเอง" — ต้องการส่งอีเมล/LINE อัตโนมัติไหม
41. ยังไม่มี rate limit ที่ login/register — ควรเพิ่มก่อนขึ้นจริง
42. Viewer (ดูอย่างเดียว) เห็นได้ทุกโครงการใน workspace — ต้องการสิทธิ์รายโครงการไหม
